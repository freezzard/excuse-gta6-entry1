Entry for the make.fun bounty **The Excuse That Almost Works**. `main.ts` runs a local tournament of eight original one-line excuses, scored against the judge's brief — believable first (a real, specific, boring workplace detail), funny on its own terms second, hurried-text feel third, fresh angle fourth — and writes the winning line (98 characters, 18 words) to `/output/entry.txt`. The pick is deterministic: every run writes byte-identical output.

The winning excuse: a VPN that keeps dropping every ten minutes since the update, and IT's own instruction to wait till Thursday — the excuse authorises itself.

## Run it

```sh
node main.ts
```
